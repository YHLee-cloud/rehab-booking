復健科自費療程預約系統 - Windows 安裝說明
======================================

安裝（第一次，或要換一台電腦時）：
1. 把這個資料夾整個複製到目標 Windows 電腦（隨意位置，例如桌面）。
2. 對 install.bat 點右鍵 -> 「以系統管理員身分執行」。
   (若直接雙擊，會跳出 UAC 視窗要求管理員權限，請按「是」)
3. 跑完會顯示存取網址，本機用 https://localhost:3000，
   診所內其他電腦/手機用畫面顯示的區網 IP，例如 https://192.168.1.10:3000
4. 瀏覽器第一次連線會顯示「不安全」/「連線不是私人連線」的警告，這是正常現象
   （因為是自動產生的自簽憑證），點選「進階」->「繼續前往」即可。
5. 預設帳號 admin，密碼 admin123，登入後請立即到「內部維護」修改密碼。

完成後，這台電腦每次開機都會自動啟動系統，不需要再重新安裝 Node.js、
不需要再執行任何指令 —— 就像安裝一般軟體一樣。

移除：
對 uninstall.bat 點右鍵 -> 「以系統管理員身分執行」。
（不會刪除資料，病患資料庫與備份會保留在安裝資料夾內的 data 資料夾）

升級到新版本：
之後若程式有更新，把新的 RehabBookingSystem.exe 和 public 資料夾放進來（取代舊的），
重新執行一次 install.bat 即可（既有的 data 資料夾內容不會被覆蓋）。
